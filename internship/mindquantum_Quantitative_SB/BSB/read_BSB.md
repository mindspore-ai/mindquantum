## 一、BSB算法理论基础

### 1.1 Ising模型与BSB算法

BSB算法是一种基于Ising模型的连续动力学优化方法，用于求解二次二元规划（QBP）问题。其核心思想是通过模拟量子分叉动力学，使系统从初始状态演化到目标函数的局部最优解。

### 1.2 核心更新公式

#### 梯度计算
$$
\nabla f(x)_i = h_i + 0.5 \sum_{j} J_{ij} x_j
$$
- $h_i$：一阶项系数（线性项）
- $J_{ij}$：二次项系数
- $x_j$：自旋变量（连续变量，范围$[0,1]$）

#### 状态更新
$$
\frac{dy}{dt} = -(1-p(t))(x-0.5) + \xi \nabla f(x) \quad \text{(动量更新)}
$$
$$
\frac{dx}{dt} = y \quad \text{(位置更新)}
$$
- $p(t) = \frac{t}{T}$：时间相关参数，从0增加到1
- $\xi$：耦合强度参数（本项目使用0.365）
- $dt$：时间步长（固定0.1）

#### 边界约束
当 $x < 0$ 或 $x > 1$ 时：
- 投影到边界：$x \rightarrow \{0, 1\}$
- 清零动量：$y \rightarrow 0$

### 1.3 能量函数

Ising模型的能量函数（哈密顿量）：
$$
H(x) = \sum_{i} h_i x_i + 0.5 \sum_{i,j} J_{ij} x_i x_j + C
$$

优化目标：**最大化**能量函数

## 二、QPLIB问题数据读取与求解

### 2.1 QPLIB格式概述

QPLIB（Quadratic Programming Library）是一个标准化的二次规划问题库，包含大量基准测试问题。每个QPLIB文件包含完整的问题定义：

```
QPLIB文件结构示例 (QPLIB_3565.qplib):
----------------------------------------
第1行: QPLIB_3565              # 问题名称
第2行: QBN                       # 问题类型 (QBN=Quadratic Binary)
第3行: maximize                  # 优化方向 (minimize/maximize)
第4行: 276                       # 变量数量
第5行: 528                       # 二次项数量
第6-533行: i j J_ij              # 二次项 (变量索引i, j和系数J_ij)
第534行: 0.0                      # 默认线性项值
第535行: 182                      # 非零线性项数量
第536-717行: i h_i                # 线性项 (变量索引i和系数h_i)
第718行: 0.0                      # 常数项
----------------------------------------
```

**注**：精确最优解来自 QPLIB 官方数据库，作为性能评估的基准。

### 2.3 BSB求解流程

```
BSB算法求解流程：
----------------------------------------
1. 读取QPLIB文件 (qplib_parser.h)
   ├── 解析问题基本信息
   ├── 读取二次项系数矩阵 J_ij
   ├── 读取线性项系数向量 h_i
   └── 计算缩放因子和xi参数

2. 初始化BSB求解器
   ├── 设置初始状态 x ~ U(0,1)
   ├── 设置初始动量 y = 0
   └── 设置迭代参数 (xi=0.365, dt=0.1)

3. 迭代优化
   ├── 计算梯度 ∇f(x)
   ├── 更新动量 y ← y + dt × [-(1-p)(x-0.5) + ξ∇f(x)]
   ├── 更新位置 x ← x + dt × y
   ├── 边界投影 x ∈ [0,1]
   └── 重复max_iters次

4. 计算最终能量
   └── E = ∑h_i x_i + 0.5∑J_ij x_i x_j + C

5. 输出结果
   ├── 目标函数值
   ├── 求解时间
   ├── 解向量 (二进制)
   └── 解密度统计
----------------------------------------
```

### 2.4 性能评估指标

**Q值（Quality Ratio）**：衡量求解质量
$$
Q = \frac{\text{求解器能量值}}{\text{精确最优解}}
$$

对于最大化问题：
- $Q = 1.0$：达到精确最优解
- $Q > 1.0$：超出最优解（可能）
- $Q < 1.0$：低于最优解
- $Q > 0.99$：高质量解（>99%）

**加速比（Speedup）**：衡量计算效率
$$
\text{加速比} = \frac{\text{CPU运行时间}}{\text{GPU运行时间}}
$$

#### 量化策略

#### 最新性能数据
- **求解时间**：6832.279 ms
- **能量值**：271.702
- **Q值**：0.9645（96.45%接近度）
- **与精确解差距**：-10.3（3.65%）⚠️ **精度损失明显**

#### 关键发现
- ⚠️ **能量明显偏低**：Q=0.9645，比最优解差10.3（3.65%）⚠️
- ✅ **CPU中相对最快**：比CPU_fp16快约11%
- ✅ **FP8内存效率**：4x内存压缩
- ❌ **精度不足**：不适合对精度要求高的场景

- ✅ **高质量能量**：Q=0.9929

- ✅ CPU实现中速度中等
